# Солемер — калькулятор солёности морской воды (PWA)

Офлайн-калькулятор для рифового аквариума: показание стеклянного ареометра
(Aqua Medic Salimeter, шкала 1.000–1.040, градуирован при 25 °C) и температура воды →
практическая солёность по EOS-80 (UNESCO 1981) с поправкой на расширение стекла.
Обратный режим «что должен показать ареометр», история с графиком, подмена воды,
настройки и фоновая пиксельная анимация на Canvas 2D.

Стек: Vite 8 · Preact 10 · TypeScript (strict) · @preact/signals. Без UI-китов и внешних
запросов: шрифт Manrope лежит локально, CSP без `unsafe-inline`/`unsafe-eval`.

## Команды

```bash
npm install --include=dev   # NODE_ENV=production на машине пропускает devDependencies без этого флага
npm run dev                 # dev-сервер http://localhost:5173
npm run build               # tsc + vite build → dist/ (service worker генерируется плагином)
npm run preview             # http://127.0.0.1:4173 — отдаёт dist/
npm test                    # Vitest: unit + компонентные тесты
npm run test:cov            # то же с покрытием (src/calc — порог 100 %)
npm run test:e2e            # Playwright (iPhone 13 и Pixel 7, Chromium); перед этим npm run build
npm run lint                # ESLint (type-checked), 0 предупреждений
```

E2E использует системный Chromium из `SALIMETER_CHROME` (по умолчанию `/opt/browser/chrome`);
на другой машине выполните `npx playwright install chromium` и укажите путь или уберите
`executablePath` в `playwright.config.ts`.

## Деплой и установка на телефон

`dist/` — статические файлы с относительными путями (`base: './'`), работают из корня
или из подпапки на любом HTTPS-хостинге (GitHub Pages, Cloudflare Pages, Netlify, свой nginx).
PWA устанавливается только с HTTPS (или с `localhost`).

1. Залейте содержимое `dist/` на хостинг.
2. Откройте адрес на телефоне: iOS — Safari → «Поделиться» → «На экран Домой»;
   Android — Chrome предложит установку или меню → «Установить приложение».
3. После первого открытия приложение полностью работает без сети; новая версия
   подхватывается service worker'ом и предлагает «Обновить».

## Структура

- `src/calc/` — расчёт: `eos80.ts` (плотность, метод Ньютона), `pss78.ts` (проводимость),
  `salinity.ts` (ареометр, поправка на стекло, обратный режим), `water.ts` (подмена/долив), `format.ts`.
- `src/store/` — IndexedDB (`db.ts`), настройки, журнал замеров, CSV.
- `src/ui/` — экраны и элементы управления; `src/bg/` — пиксельные силуэты и движок анимации.
- `sw/sw.ts` — service worker (список файлов подставляется при сборке в `vite.config.ts`).
- `tests/unit`, `tests/component`, `tests/e2e` — тесты; `scripts/` — иконки, скриншоты, замеры.

## Формулы

- Температура ITS-90 → IPTS-68: `t68 = 1.00024·t`.
- Шкала: г/см³ → ×1000; SG 25/25 → ×997.047; SG 25/4 → ×999.972 (кг/м³).
- Поправка на стекло: `ρ = ρ_шк / (1 + β(t − 25))`, β = 2.5·10⁻⁵ (натриево-кальциевое) или 1.0·10⁻⁵ (боросиликат).
- Солёность: решение `ρ(S, t, 0) = ρ` по EOS-80 методом Ньютона (старт 35, |ΔS| < 1e-6).
- Погрешность: пересчёт для R ± 0.0005. Абсолютная солёность: `S_A ≈ 1.004715·S`.
- Проводимость при 25 °C: обратная PSS-78, `C(35,15,0) = 42.914 мС/см`.
